## Configuration

SMTP settings are read from environment variables. Copy `.env.example` to `.env`
and fill in your own values (`MAIL_HOST`, `MAIL_PORT`, `MAIL_USERNAME`,
`MAIL_PASSWORD`, `MAIL_ENCRYPTION`, `MAIL_FROM_ADDRESS`, `MAIL_FROM_NAME`).
Never commit `.env` — it is listed in `.gitignore`.
